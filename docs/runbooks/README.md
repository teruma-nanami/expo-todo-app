# 📖 runbooks/ — 運用手順書

## 役割

デプロイ・障害対応・定期メンテナンスなど、**本番運用に関わる手順書**を格納するディレクトリです。

「誰がやっても同じ結果になる」ことを目的として、コマンドや手順を具体的に記述します。

## ファイル構成の例

```
runbooks/
├── README.md           # このファイル
├── deployment.md       # デプロイ手順
├── rollback.md         # ロールバック手順
├── incident.md         # 障害対応フロー
└── maintenance.md      # 定期メンテナンス手順
```

## 記載すべき内容

### 共通で含める項目

| 項目 | 内容 |
| --- | --- |
| **概要** | この手順書が対象とする作業 |
| **実行タイミング** | いつ・どんな状況で使うか |
| **前提条件** | 必要な権限・ツール・環境 |
| **手順** | ステップ番号付きで具体的なコマンドや操作を記載 |
| **確認方法** | 作業成功を確認する方法 |
| **ロールバック** | 失敗した場合の戻し方 |
| **担当・連絡先** | 問題発生時の連絡先 |

### ファイル別の記載内容

| ファイル | 記載すべき内容 |
| --- | --- |
| `deployment.md` | デプロイ前チェック・手順・デプロイ後確認・夜間デプロイのルール |
| `rollback.md` | ロールバック判断基準・手順・DB マイグレーションの戻し方 |
| `incident.md` | 障害検知方法・対応フロー・エスカレーション先・事後レビュー手順 |
| `maintenance.md` | 定期実行タスク・DBバックアップ確認・ログローテーション確認 |
