# 📐 api/ — API仕様書

## 役割

プロジェクトの **RESTful API 仕様書**を格納するディレクトリです。  
`/api-design` スキルによって自動生成されます。

## ファイル命名規則

```
{リソース名}.md
例: users.md / products.md / auth.md
```

## 記載すべき内容

| 項目 | 内容 |
| --- | --- |
| **エンドポイント一覧** | メソッド・パス・概要・認証要否を表形式で |
| **各エンドポイント詳細** | リクエスト・レスポンス・バリデーション・ビジネスルール |
| **エラーレスポンス** | ステータスコード別のエラー形式 |

## テンプレート

```markdown
# {リソース名} API

## エンドポイント一覧

| メソッド | パス | 概要 | 認証 |
| --- | --- | --- | --- |
| GET | /api/{resources} | 一覧取得 | 要 |
| POST | /api/{resources} | 新規作成 | 要 |
| GET | /api/{resources}/{id} | 詳細取得 | 要 |
| PUT | /api/{resources}/{id} | 更新 | 要 |
| DELETE | /api/{resources}/{id} | 削除 | 要 |

---

## GET /api/{resources} — 一覧取得

### リクエスト

**クエリパラメータ:**

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| page | integer | — | ページ番号（デフォルト: 1） |
| per_page | integer | — | 件数（デフォルト: 20） |

### レスポンス（200）

\`\`\`json
{
  "data": [
    {
      "id": 1,
      "name": "example"
    }
  ],
  "meta": {
    "current_page": 1,
    "total": 100
  }
}
\`\`\`

---

## POST /api/{resources} — 新規作成

### リクエスト

\`\`\`json
{
  "name": "string（必須）"
}
\`\`\`

**バリデーション:**

| フィールド | ルール |
| --- | --- |
| name | required / string / max:255 |

### レスポンス（201）

\`\`\`json
{
  "data": {
    "id": 1,
    "name": "example"
  }
}
\`\`\`

### エラーレスポンス（422）

\`\`\`json
{
  "message": "バリデーションエラーが発生しました",
  "errors": {
    "name": ["名前は必須です"]
  }
}
\`\`\`
```

## レスポンス共通規約

| コード | 用途 |
| --- | --- |
| 200 | 成功 |
| 201 | 作成成功 |
| 401 | 未認証 |
| 403 | 権限なし |
| 404 | リソース未検出 |
| 422 | バリデーション / ビジネスロジックエラー |
| 500 | サーバーエラー |
