# 🔌 integrations/ — 外部サービス連携仕様書

## 役割

外部 API・SaaS・サードパーティサービスとの**連携仕様**を格納するディレクトリです。

連携先サービスの仕様変更や担当者交代があっても対応できるよう、接続方法・認証・データ形式・エラーハンドリングを記録します。

## ファイル命名規則

```
{サービス名}.md
例: stripe.md / firebase.md / sendgrid.md / google-oauth.md
```

## 記載すべき内容

| 項目 | 内容 |
| --- | --- |
| **サービス概要** | 何のために使っているか・プラン・利用機能 |
| **認証方法** | APIキー・OAuth・シークレットの管理場所 |
| **利用している API / 機能** | エンドポイント・SDK メソッドの一覧 |
| **データフロー** | どの画面・処理から呼び出しているか |
| **エラーハンドリング** | エラーコード別の対処方法 |
| **レート制限** | API の利用上限・対策 |
| **テスト方法** | sandbox / モック環境の使い方 |
| **管理コンソール URL** | サービスの管理画面・ダッシュボードへのリンク |
