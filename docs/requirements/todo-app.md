# 要件定義：expo-todo-app

## 概要

Expoの学習を目的としたシンプルなモバイルTODOアプリ。  
転職活動のポートフォリオとしても使用予定。

## アクター

- 自分のみ（認証なし）

## ユーザーストーリー

- ユーザーとして、TODOを追加したい。なぜならやることを記録したいから。
- ユーザーとして、TODOの一覧を見たい。なぜなら何が残っているか把握したいから。
- ユーザーとして、TODOを完了にしたい。なぜなら達成したことを記録したいから。
- ユーザーとして、TODOを削除したい。なぜなら不要なものを消したいから。
- ユーザーとして、TODOのタイトルを編集したい。なぜなら内容を修正したいから。

## 機能要件

| 機能 | 受け入れ条件 |
|------|-------------|
| TODO一覧表示 | 登録済みTODOがリスト表示される。完了済みは視覚的に区別される（打ち消し線など） |
| TODO追加 | 追加画面でタイトルを入力して保存できる。空文字は保存不可 |
| TODO編集 | 追加画面と共用。既存タイトルを編集して保存できる |
| TODO完了トグル | チェックでcompleted状態が切り替わりAsyncStorageに反映される |
| TODO削除 | スワイプで削除できる。AsyncStorageから削除される |
| データ永続化 | AsyncStorageに保存され、アプリ再起動後も維持される |

## データモデル

```ts
type Todo = {
  id: string        // UUID
  title: string     // タイトル
  completed: boolean // 完了フラグ
  createdAt: string  // 作成日時（ISO 8601）
}
```

## 画面構成

| 画面 | 役割 |
|------|------|
| List Screen | TODO一覧・スワイプ削除・完了トグル |
| Add/Edit Screen | タイトル入力・保存（追加・編集を共用） |

## 技術スタック

| 項目 | 技術 |
|------|------|
| フレームワーク | Expo (React Native) |
| ナビゲーション | Expo Router |
| スタイリング | NativeWind（TailwindCSS） |
| 永続化 | AsyncStorage |
| 言語 | TypeScript |

## 非機能要件

- 認証不要（シングルユーザー）
- オフライン動作（AsyncStorageのみ、サーバー通信なし）
- iOS・Android両対応
