# 🌿 branch — ブランチ作成

Git Flow に沿って正しいベースブランチから新ブランチを作成するスキル。

## 使い方

```
/branch
```

## ブランチ種別

| 種別 | 命名 | ベース |
| --- | --- | --- |
| 新機能 | `feature/{タスク名}` | `develop` |
| 本番緊急修正 | `hotfix/{内容}` | `main` |
| リリース準備 | `release/{x.x.x}` | `develop` |

## プロセス

1. ブランチの種類を確認
2. ブランチ名（英語 kebab-case）を提案
3. ユーザーの承認を得る
4. 適切なベースブランチから作成

## ルール

- ブランチ名は英語 kebab-case（例: `feature/user-registration`）
- 承認なしにブランチを作成しない
