# リファクタリング提案

対象コードを分析し、CLAUDE.md のアーキテクチャに沿ったリファクタリングを提案する。

## パイプライン

- 前提: 対象コードが存在すること
- 読込: ソースコード
- 出力: 提案（実施はユーザー承認後）
- 関連: `/review` と併用可

## 分析観点

### 1. コードの臭い

- 長すぎるメソッド / クラス
- 重複コード
- 深いネスト（3階層超）
- 不適切な命名
- God Class（なんでもやるクラス）

### 2. アーキテクチャ違反（CLAUDE.md 準拠）

- Controller にビジネスロジックが含まれていないか
- Action 内で Eloquent が直接使われていないか（Repository に委譲すべき）
- Service に本来 Action にあるべきビジネスフローが含まれていないか
- Service 内で Eloquent が直接使われていないか（Repository に委譲すべき）
- Repository にビジネス判断が含まれていないか（データアクセスのみが責務）
- Model にビジネスフローが含まれていないか
- フロント: features 間で hooks/api が直接参照されていないか

### 3. パフォーマンス

- N+1 問題
- 不要なクエリ
- メモリ効率

## 出力形式

各提案:

- **対象**: ファイルパスと行番号
- **問題**: 何が問題か
- **改善案**: 具体的な修正方法
- **影響範囲**: 他への影響
- **優先度**: 高 / 中 / 低

## ルール

- 動作を変えないリファクタリングに限定
- 段階的に改善できるよう提案
- 実施はユーザー承認後
