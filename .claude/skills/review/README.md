# 🔍 review — コードレビュー

`code-reviewer` エージェントと Codex を並列起動し、多角的なコードレビューを行うスキル。

## 使い方

```
/review
```

「レビューして」「コードレビュー」「コードをチェックして」「変更内容を確認して」でも起動。

## パイプライン

```
前提: 対象コードが存在すること
読込: ソースコード / docs/features/ / docs/api/
出力: レビュー結果（重要度別）
関連: /refactor と併用可
```

## 並列レビュー構成

| エージェント | 観点 |
| --- | --- |
| **code-reviewer** | CLAUDE.md 規約、設計書乖離、認証・認可 |
| **Codex**（疎通 NG 時は code-reviewer）| セキュリティ、エラーハンドリング、パフォーマンス、Next.js 固有 |

## 出力

🔴 重大 / 🟡 注意 / 🔵 提案 の3段階で分類して統合レポートを出力。

- 設計書乖離は機械的に重大扱いしない
- 「実装を直すべきか、設計書を直すべきか」の判断を明示

## ルール

- レビュー結果の修正は自動で行わない（ユーザーの判断に委ねる）
- 設計書が存在する場合は設計書乖離を必須観点として追加
- スコープ外の根本問題は別 Issue 起票で提案する
