# 🧪 test-gen — テスト生成

実装されたコードに対してテストを生成するスキル（PHPUnit ベース）。

## 使い方

```
/test-gen
```

## パイプライン

```
前提: /implement 完了
読込: ソースコード / docs/api/
出力: テストコード
次:   /review（任意）
```

## テスト配置

| ディレクトリ | 対象 |
| --- | --- |
| `tests/Unit/` | Action, Service の単体テスト |
| `tests/Feature/` | API エンドポイントの結合テスト |

## 構造（AAA パターン）

1. **Arrange** — テストデータ準備（Factory 活用）
2. **Act** — テスト対象の実行
3. **Assert** — 結果検証

## カバレッジ

- 正常系: 期待通りの動作
- 異常系: バリデーションエラー・認証エラー・権限エラー・リソース未検出
- 境界値: 空文字・最大長・0・null

## ルール

- メソッド名は日本語: `test_ユーザーが正常に作成される()`
- Factory でテストデータを作成する
- 外部 API 依存はモック化する
- 1テストメソッド = 1つの検証観点
- `RefreshDatabase` トレイトで毎回 DB 初期化
- `make test` で実行確認する
